# TAMEER HR

Веб-приложение для учёта рабочего времени, графиков и замен, кадровых заявок, KPI и зарплаты. В комплекте сервер, дашборд, кабинеты в Telegram Mini Apps и исходники Android-приложения руководителя.

## Запуск на своём компьютере

Нужен Node.js 24. Для просмотра кадровых модулей дополнительные пакеты не требуются. Для кадров с RTSP-камер нужен FFmpeg в PATH.

1. Скопируйте `.env.example` в `.env` и задайте свой `ADMIN_PASSWORD` длиной от 12 символов.
2. Запустите `node --env-file=.env server.mjs`.
3. Откройте [локальный дашборд](http://127.0.0.1:3000) и войдите как `admin` со своим паролем.

С Docker Compose после подготовки `.env` запустите `docker compose up -d --build`. Приложение слушает порт 3000 на локальном адресе. SQLite и файлы приложения хранятся в отдельном томе Docker.

## Настройка

- Для удалённого доступа поднимите HTTPS-прокси перед приложением и задайте его адрес в `PUBLIC_URL`. Для Telegram Mini Apps требуется HTTPS.
- В дашборде в разделе «Telegram» подключите отдельных ботов для отметок смен, зарплаты и подбора. `ATTENDANCE_BOT_USERNAME` и `RECRUITMENT_BOT_USERNAME` позволяют закрепить ожидаемые имена без символа `@`.
- Укажите `ATTENDANCE_AUTO_CLOSE_SINCE` в формате `YYYY-MM-DD`, чтобы включить автозакрытие обычных дневных смен с отметкой 18:15 по часовому поясу `STORE_TZ`.
- Интеграции с «МойСклад» и хранилищем видео настраиваются в админ-панели. Учебные видео и модели анализа посетителей подключаются отдельно. В репозитории есть исходники анализа посетителей в `visitor-worker/`.
- Инструкция по сборке и размещению Android-приложения находится в [android/README.md](android/README.md).

Шаблоны импорта и отчёты Excel формируются приложением при скачивании.

Запускайте проверки серверных модулей командой `node --test` из корня проекта.
